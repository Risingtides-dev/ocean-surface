After four invalid snapshot attempts, `sync_session_projection` calls `restart_projection` (`daemon.rs:3454-3461`), which increments the generation and immediately spawns another four-attempt cycle (`3362-3374`). A permanently incompatible projection version, malformed payload, or repeated reset can create a continuous GET/restart loop without terminal fallback or meaningful backoff.
- **Blocker — high:** Projection-to-legacy fallback after a tail reset can preserve stale live state. `restart_projection` only resets transports/status (`daemon.rs:3362-3373`), while `install_legacy_snapshot` updates transcript/title/model but does not clear `streaming`, `active_turn_id`, `browser_active`, or pending permissions (`3493-3514`). If projection disappears during resync, a finished turn can remain visibly running after legacy hydration.

Native EventSource independently resumes from the SSE ID, so an ID/body mismatch can make browser resume position diverge from the reducer cursor. The implementation plan explicitly required this validation.
