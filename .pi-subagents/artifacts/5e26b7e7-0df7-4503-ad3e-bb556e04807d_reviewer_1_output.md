- **Correct:** Session saves clone, increment, fsync, rename, then update caller state only after rename (`crates/ocean-agent/src/session/mod.rs:364-403`).
- **Correct:** Projection appends and folded state updates share one SQLite transaction, with wake publication after commit (`crates/ocean-daemon/src/session_projection.rs:351-381`).
- **Correct:** `SurfacePatch`, `SlackCanvas`, and `Extension` are excluded before sequence allocation (`crates/ocean-daemon/src/session_projection.rs:296-304`). No Observatory code/spec files were changed.
- **Correct:** Restart creates a new epoch; cursor validation explicitly rejects malformed, wrong-epoch, wrong-session, future, retention, fault, and lease failures (`crates/ocean-daemon/src/session_projection.rs:160-216,589-697`).
- **Correct:** SSE subscribes before paging, treats broadcast as a wake hint, re-pages after lag, emits matching SSE `id`, honors `Last-Event-ID`, and observes shutdown/client closure/backpressure (`crates/ocean-daemon/src/main.rs:6875-7050`).
- **Correct:** Lease acknowledgement advances only from a new request cursor; internally queued pages renew expiry without acknowledging delivery (`crates/ocean-daemon/src/session_projection.rs:505-556,653-734`).

- **Blocker (high): Completed thinking loses its type on every normalized checkpoint.** `transcript_entry` calls `text_from_content`, which concatenates `Content::Text` and `Content::Thinking` into one assistant string (`crates/ocean-agent/src/session/mod.rs:990-1018,1050-1060`). The checkpoint carries only this flattened transcript (`crates/ocean-agent/src/session/mod.rs:920-940`), so the Surface reconstructs completed thinking as ordinary assistant text rather than a durable thinking block. This violates the required durable completed-thinking snapshot semantics.

- **Blocker (high): Folded cancellation removes unrelated pending permissions.** `OceanEvent::Cancelled` clears the entire session permission map (`crates/ocean-daemon/src/session_projection.rs:123-129`), although cancellation envelopes carry `request_id`. The reviewed Surface correctly removes only permissions belonging to that request and falls back to session-wide clearing only for legacy frames (`/private/tmp/ocean-surface-session-projection-20260717/crates/ocean-surface-ui/src/daemon.rs:5260-5334`). A fresh projection snapshot can therefore disagree with the live consumer and hide unrelated permission cards.

- **Blocker (contract): Persistence checkpoints consume visible sequence numbers.** `checkpoint()` inserts a visible event and increments `latest_seq` (`crates/ocean-daemon/src/session_projection.rs:411-427`). The supplied implementation contract explicitly says internal persistence checkpoints do not consume a visible sequence and sets `checkpoint_seq` to the latest already-committed visible sequence. The Surface matches the implemented visible-checkpoint protocol, but the requested `plan.md` and `progress.md` were absent, so no reviewed amendment authorizes this departure.

- **Note:** Components are deliberately omitted from folded state and reconstructed from ordered successful call/result pairs (`crates/ocean-daemon/src/session_projection.rs:61-117`). This aligns with the supplied Surface consumer, but differs from the original contract’s folded `components` field.
- **Note:** Pressure compaction deletes all eligible checkpoint-covered rows per session rather than globally selecting the oldest eligible rows first (`crates/ocean-daemon/src/session_projection.rs:736-800`). It remains continuity-safe but does not precisely implement the stated oldest-first pressure policy.
