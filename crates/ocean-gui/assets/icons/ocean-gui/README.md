# Ocean GUI shell icons

These files are pinned Lucide icons, renamed to preserve Ocean GUI's existing
asset paths. They are rendered as monochrome SVGs by GPUI with `text_color`.

- Upstream: <https://github.com/lucide-icons/lucide>
- Pinned revision: `658573b0171e693bc965c167592cc0b92d002a3e`
- License: ISC, with MIT coverage for the Feather-derived icons listed in
  [`LICENSE-LUCIDE`](LICENSE-LUCIDE)

Mapping:

```text
bell.svg          <- bell
blocks.svg        <- blocks
book.svg          <- book-open
chat.svg          <- message-circle
check_circle.svg  <- circle-check
code.svg          <- code
database_zap.svg  <- database-zap
diff.svg          <- git-compare-arrows
file_doc.svg      <- file-text
file_markdown.svg <- file-code
file_text.svg     <- file-text
folder_open.svg   <- folder-open
list_todo.svg     <- list-todo
send.svg          <- send
server.svg        <- server
terminal.svg      <- terminal
tool_search.svg   <- search
user_check.svg    <- user-check
```

The prior copies came from Zed's primarily GPL-licensed icon tree and were
replaced during the public provenance audit rather than imposing that uncertain
copyleft boundary on Ocean Surface.
