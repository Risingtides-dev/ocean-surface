Migration phases

1. Remove ambiguity

Quarantine/delete ocean-gui-egui, document ocean-gui as the only supported native app, and make wrong launch paths impossible to mistake for product behavior.

2. Rename reality

Native CanvasLedger is the canvas. Retire stale tldraw-owned names, dead adapter code, and footer/debug copy that implies the old model still owns the surface.

3. Extract product slices

Move render/state/event chunks out of view.rs by product seam: chrome, agent thread, canvas workspace, vault editor, LiveKit panel, command palette.

4. Make Agent-first explicit

Default launch and empty states should orient around creating/attaching to a session. Canvas and vault become workspace surfaces attached to that session.

Safety rule

No rewrite. No new behavior until the old behavior has a named module and a green check. Each phase keeps cargo check -p ocean-gui, cargo test -p ocean-gui, and the LiveKit feature check green.
